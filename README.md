# ATAG Website

A responsive two-page ATAG website with a green animated theme and Discord invite button.

## Files
- `index.html` — Home page
- `privacy.html` — Privacy Policy page
- `styles.css` — Shared styling, responsive layout, and animations
- `script.js` — Mobile navigation and footer year
- `banner.png` — Add your own banner image here

## Use with GitHub Pages
1. Upload these files to the root of your GitHub repository.
2. Upload your image and name it exactly `banner.png` (same folder as `index.html`).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose your branch (usually `main`) and folder (`/(root)`), then save.
5. Open the Pages URL GitHub provides.

The banner file is referenced as `banner.png`; it is not included because you said you will upload it yourself.
